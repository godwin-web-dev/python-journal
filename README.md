# Python Learning Workspace

This repository contains organized code, notebooks, and notes for learning Python, data science, Linux commands, APIs, MongoDB, and FastAPI. Each folder covers a specific topic with practical examples, exercises, and reference materials.

---

## Directory Structure

### Core Python

- **01-strings/**  
  String methods and manipulations.

- **02-conditional-operator/**  
  Conditional statements and logic.

- **03-lists/**  
  List operations, copying, and manipulation.

- **04-loops/**  
  For and while loop examples.

- **05-slice-operator/**  
  Slicing techniques for sequences.

- **06-sets/**  
  Set operations and properties.

- **07-dictionary/**  
  Dictionary creation and manipulation.

- **08-list-comprehension/**  
  List comprehensions for concise code.

- **09-kwrgs-args-unpack/**  
  Usage of `*args`, `**kwargs`, and unpacking.

- **10-scope/**  
  Global and local variable scope.

- **11-lamda-functions/**  
  Lambda functions, map, filter, and reduce.

- **12-practice/**  
  Practice problems and solutions.

### Data Science

## How to Use

1. **Browse Topics:**  
   Each folder is self-contained. Open any folder to explore code and notes on that topic.

2. **Run Code:**  
   - Python scripts (`.py`) can be run directly with Python 3.
   - Jupyter notebooks (`.ipynb`) can be opened in JupyterLab or VS Code.

3. **Practice:**  
   Try the exercises in the `12-practice/` and `14-recap/` folders to test your understanding.

4. **Reference:**  
   Use the markdown files in `16-linux-commands/` and the MongoDB cheat sheet for quick command lookups.

## Requirements

- Python 3.7+
- [Jupyter Notebook](https://jupyter.org/) (for `.ipynb` files)
- [NumPy](https://numpy.org/)
- [Pandas](https://pandas.pydata.org/)
- [Requests](https://docs.python-requests.org/)
- [PyMongo](https://pymongo.readthedocs.io/)
- [FastAPI](https://fastapi.tiangolo.com/)
- [Pydantic](https://docs.pydantic.dev/)

Install dependencies with:
```sh
pip install numpy pandas requests pymongo fastapi pydantic
```
